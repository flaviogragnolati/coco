# Identidad de Ingeniería Quasar

## Denominación

La empresa se denomina **Ingeniería Quasar**. La marca visible y los logotipos usan **Quasar**. No usar `Quasar Analytic` ni `Analytic`; esas denominaciones históricas no tienen autoridad vigente.

## Logotipos canónicos

Los ocho archivos bajo `assets/logos/` son los únicos logotipos autorizados:

- `horizontal-color.png` y `vertical-color.png` para fondos claros;
- `horizontal-bc.png` y `vertical-bc.png` para fondos oscuros;
- `horizontal-negro.png`, `vertical-negro.png`, `horizontal-blanco.png` y `vertical-blanco.png` para reproducción monocromática.

Seleccionar por contraste y orientación. Insertar el archivo oficial; nunca reconstruir la palabra Quasar ni vectorizar el isotipo por aproximación.

## Paleta canónica

| Token | Valor | Uso |
|---|---|---|
| `quasar.blue` | `#27367E` | Marca, títulos, estructura y fondos hero |
| `quasar.green` | `#69BC9B` | Acento, progreso, conexión y énfasis positivo |
| `quasar.ink` | `#1D1D1B` | Texto principal y palabra del logotipo |
| `quasar.white` | `#FFFFFF` | Fondo, espacio negativo y texto inverso |
| `quasar.black` | `#000000` | Reproducción técnica monocromática |
| `quasar.gray` | `#6C6C6B` | Texto secundario y contexto |
| `quasar.line` | `#DDDDDD` | Divisores y grillas discretas |
| `quasar.blue.soft` | `#DFE1EC` | Paneles y filas alternas |
| `quasar.blue.min` | `#EEEFF5` | Separación leve |
| `quasar.green.soft` | `#CAE8DC` | Superficie de énfasis con texto oscuro |
| `quasar.green.min` | `#F3FAF7` | Recomendación, cierre o estado positivo |

Los alias por medio mapean a estos tokens: documentos usan `navy`, `mint`, `text`, `muted`, `line`, `navy_tint` y `mint_tint`; decks usan `blue`, `green`, `ink`, `gray`, `blue_soft` y `green_soft`. Un alias no crea otro color canónico.

## Reglas no negociables

- Conservar proporción, inclinación, color, espaciado interno y un área libre mínima del `25 %` de la altura del logotipo.
- No aplicar sombras, contornos, gradientes, transparencias, biseles ni efectos.
- Usar el logotipo completo en portada y cierre; reservar el isotipo para marca secundaria, separador, numeración o textura discreta.
- No ubicar el logotipo sobre ruido visual o contraste insuficiente.
- Usar azul como dominante y verde como acento; no usar color como único indicador.
- Mantener **Ingeniería Quasar** como texto institucional separado cuando corresponda; no agregarlo dentro del logotipo.
