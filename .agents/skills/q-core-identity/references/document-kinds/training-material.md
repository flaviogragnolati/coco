Use para una experiencia de aprendizaje trazada a resultados observables y al alcance del entregable.

## Secciones mínimas / Minimum sections

Audiencia y prerrequisitos; resultados; agenda; conceptos; demostraciones; actividades con tiempo y producto esperado; evaluación; recursos; seguimiento.

## Salida / Exit checklist

Cada resultado tiene práctica o evidencia; soluciones quedan en notas cuando corresponda; datos ficticios se rotulan; accesibilidad y confidencialidad están verificadas.
