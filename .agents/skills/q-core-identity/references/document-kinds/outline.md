# Esquema / Outline

Use como `working-document` opcional cuando la estructura de un entregable extenso necesita confirmación antes de redactar.

```yaml
deliverable_id: DEL-nnn
deliverable_kind: outline
version: x.y
declared_scope: "..."
criteria_ref: [AC-nnn]
source_findings: [FND-nnn]
status: Working
classification: public | internal | confidential | restricted
```

## Secciones mínimas / Minimum sections

Audiencia y decisión; propósito; fuentes; jerarquía de secciones; mensaje por sección; evidencia prevista; exclusiones; preguntas abiertas.

## Salida / Exit checklist

Confirmar cobertura, orden y exclusiones; no escribir prosa final; identificar faltantes; archivar el outline al aprobar la versión del entregable.
