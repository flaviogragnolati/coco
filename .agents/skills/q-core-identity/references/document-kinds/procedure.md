# Procedimiento / Procedure

Use para describir una secuencia operativa repetible dentro del alcance declarado.

```yaml
deliverable_id: DEL-nnn
deliverable_kind: procedure
version: x.y
declared_scope: "..."
criteria_ref: [AC-nnn]
source_findings: [FND-nnn]
status: Working
classification: public | internal | confidential | restricted
```

## Secciones mínimas / Minimum sections

Objetivo; alcance y exclusiones; roles; entradas y prerrequisitos; pasos y decisiones; excepciones y escalamiento; controles y registros; métricas; historial.

## Salida / Exit checklist

Cada paso tiene actor y condición; decisiones y excepciones son explícitas; controles trazan a hallazgos y criterios; no se agregan compromisos comerciales.
