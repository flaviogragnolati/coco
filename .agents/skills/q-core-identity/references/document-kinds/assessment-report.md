# Informe de evaluación / Assessment report

Use para comunicar alcance, evidencia, hallazgos y brechas confirmadas; no diseñar el remedio dentro del diagnóstico.

```yaml
deliverable_id: DEL-nnn
deliverable_kind: assessment-report
version: x.y
declared_scope: "..."
criteria_ref: [AC-nnn]
source_findings: [FND-nnn]
status: Working
classification: public | internal | confidential | restricted
```

## Secciones mínimas / Minimum sections

Resumen; alcance y método; evidencia y limitaciones; estado actual; hallazgos con confianza; brechas; riesgos; asuntos abiertos; próximos pasos owner-routed.

## Salida / Exit checklist

Cada hallazgo resuelve evidencia; hipótesis permanecen rotuladas; método y límites son visibles; recomendaciones no exceden la autoridad del owner.
