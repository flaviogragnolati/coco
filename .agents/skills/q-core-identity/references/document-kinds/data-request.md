# Solicitud de datos / Data request

Use para pedir evidencia mínima y gobernada; no solicitar secretos, credenciales ni datos fuera del alcance aprobado.

```yaml
deliverable_id: DEL-nnn
deliverable_kind: data-request
version: x.y
declared_scope: "..."
criteria_ref: [AC-nnn]
source_findings: [FND-nnn]
status: Working
classification: public | internal | confidential | restricted
```

## Secciones mínimas / Minimum sections

Propósito y pregunta; campos y definiciones; período y granularidad; formato; owner; canal autorizado; clasificación; minimización y redacción; fecha solicitada; criterio de suficiencia.

## Salida / Exit checklist

Justificar cada campo; excluir credenciales y PII innecesaria; definir entrega segura; registrar limitaciones; convertir ausencias en gaps, nunca en datos inventados.
