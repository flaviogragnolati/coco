# Minuta / Minutes

Use para registrar una sesión confirmada; no convierte hipótesis u opciones en hallazgos o compromisos.

```yaml
deliverable_id: DEL-nnn
deliverable_kind: minutes
version: x.y
declared_scope: "..."
criteria_ref: [AC-nnn]
source_findings: []
status: Working
classification: public | internal | confidential | restricted
```

## Secciones mínimas / Minimum sections

Propósito y alcance; fecha y participantes; agenda; declaraciones textuales frente a paráfrasis; decisiones; acciones con dueño; evidencia adjunta; pendientes.

## Salida / Exit checklist

Confirmar atribución, decisiones y clasificación; separar verbatim de paráfrasis; registrar evidencia por ID; rutear hipótesis y opciones a sus owners.
