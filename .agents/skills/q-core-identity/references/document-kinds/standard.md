# Estándar / Standard

Use para requisitos normativos internos y verificables, no para una guía opcional.

```yaml
deliverable_id: DEL-nnn
deliverable_kind: standard
version: x.y
declared_scope: "..."
criteria_ref: [AC-nnn]
source_findings: [FND-nnn]
status: Working
classification: public | internal | confidential | restricted
```

## Secciones mínimas / Minimum sections

Propósito; ámbito; términos; requisitos obligatorios; roles; excepciones y aprobación; evidencia de cumplimiento; revisión y vigencia.

## Salida / Exit checklist

Distinguir `must` de recomendación; hacer cada requisito verificable; nombrar autoridad y excepción; conservar fuentes, versión y clasificación.
