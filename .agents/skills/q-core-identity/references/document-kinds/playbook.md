# Playbook / Playbook

Use para orientar respuestas consistentes ante escenarios conocidos sin convertir heurísticas en obligaciones.

```yaml
deliverable_id: DEL-nnn
deliverable_kind: playbook
version: x.y
declared_scope: "..."
criteria_ref: [AC-nnn]
source_findings: [FND-nnn]
status: Working
classification: public | internal | confidential | restricted
```

## Secciones mínimas / Minimum sections

Objetivo; principios; escenarios y señales; respuesta recomendada; roles; herramientas; escalamiento; ejemplos; métricas y aprendizaje.

## Salida / Exit checklist

Cada escenario tiene trigger, owner y cierre; separar obligación de orientación; marcar ejemplos ilustrativos; trazar recomendaciones a evidencia.
