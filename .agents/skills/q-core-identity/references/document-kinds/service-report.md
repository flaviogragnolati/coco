# Informe de servicio / Service report

Use para reportar un período de servicio contra compromisos registrados, sin redefinir el servicio ni inferir aceptación.

```yaml
deliverable_id: DEL-nnn
deliverable_kind: service-report
version: x.y
declared_scope: "..."
criteria_ref: [AC-nnn]
source_findings: [FND-nnn]
status: Working
classification: public | internal | confidential | restricted
```

## Secciones mínimas / Minimum sections

Período y alcance; compromisos; actividad realizada; métricas y base; incidentes y excepciones; riesgos; decisiones requeridas; próximos pasos.

## Salida / Exit checklist

Vincular cada afirmación a evidencia; rotular estimaciones; separar actividad de resultado; mostrar desviaciones y owner; no registrar aceptación por silencio.
