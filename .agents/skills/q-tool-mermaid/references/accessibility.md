# Accessibility

Add a short `accTitle` and a sentence-level `accDescr` when the diagram grammar supports them. For a grammar that does not, place equivalent alt text next to the embedding image or code block and report the limitation.

Do not encode meaning through color alone. Pair status or category colors with labels, shapes, line patterns, or grouping. Preserve sufficient foreground/background contrast in static profiles. Keep labels readable at the requested delivery size and provide SVG where scaling matters.

Accessibility lint is evidence, not a guarantee. Inspect the rendered result in its actual channel.
