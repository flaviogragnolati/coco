# Code to diagram

Accept either a small code/configuration snippet supplied in the request or a structured evidence map from `q-code-explore`, `q-code-grill-design`, `q-plan-domain-model`, or `q-plan-architecture`.

Map only observed modules, calls, dependencies, data flows, or configuration relationships. Preserve evidence pointers and mark inference. For a whole repository, return to the exploration owner rather than scanning broadly inside this tool.

The caller approves what the code means. This tool selects and encodes a representation after the evidence map is settled.
