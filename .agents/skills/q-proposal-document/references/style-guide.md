# Quasar commercial document style guide

## 1. Visual authority

Use this guide as a closed visual system. Use only the Quasar logos in `assets/`; never use a logo or contact associated with “Quasar Analytic”. Preserve the generated cover, compact header, footer band, and visible provenance reference.

## 2. Palette

| Token | HEX | Use |
|---|---|---|
| `quasar_mint` | `#69BC9B` | Accents, rules, labels, positive states |
| `quasar_navy` | `#27367E` | Titles, table headers, primary hierarchy |
| `quasar_black` | `#1C1C1C` | Logo and strongest text |
| `text` | `#1F2937` | Body |
| `muted` | `#6B7280` | Metadata and notes |
| `line` | `#D8DEE9` | Borders and separators |
| `navy_tint` | `#EEF1FA` | Alternate rows and information boxes |
| `mint_tint` | `#EAF7F2` | Summary and recommendation |
| `warning_tint` | `#FFF7D6` | Legal, risk, or dependency warning |
| `white` | `#FFFFFF` | Background and inverse text |

Derive chart colors from navy and mint only when a chart is justified and contrast remains accessible.

## 3. Typography

- Use Supera Gothic ExtraBold for cover and brand titles.
- Use Supera Gothic Regular for short cover labels.
- Use Arial for body, tables, notes, headers, and footers.
- Use no more than two font families.
- Do not condense or stretch type.
- Verify redistribution rights before sharing bundled fonts outside the authorized environment.

| Role | Font | Size | Color |

## 4. Page system

- Use portrait A4, 210 × 297 mm.
- Use 18 mm left/right body margins, 30 mm top, and 29 mm bottom.
- Use a full-page cover with the Quasar pattern.
- Use `assets/body-header.png` on interior pages.
- Show date, proposal version, abbreviated source hash, and page numbering above the footer band.
- Keep headers and footers consistent across runs.

## 5. Components

### Cover

Order: pattern, localized proposal label, client, project, subtitle, version/date, approved Quasar contact, and horizontal logo. Do not add prices, clauses, internal classification, or proposal code.

### Tables

Use navy headers with white text, alternating white and navy-tint rows, 0.5 pt line borders, explicit content-aware widths, vertically centered cells, and repeated header rows. Do not use tables to package long prose.

### Callouts

Use mint tint for summaries and recommendations, navy tint for technical or contractual information, and warning tint for legal review or critical dependencies. Keep callouts short.

### Editable fields

Use Word content controls for client identity, representative, email, date, selected alternative, and both signature blocks. Do not simulate digital fields with underscores.

## 6. Editorial voice

Use the canonical document language:

- Spanish: formal, direct Rioplatense business Spanish.
- English: neutral, direct professional English.

Define acronyms on first use, prioritize outcomes and verifiable boundaries, and distinguish estimates from commitments. Do not translate approved canonical content inside this skill.

## 7. Consistency

Do not mix A4 and Letter, reduce body below 8.5 pt, leave placeholders in issued documents, or deliver without reviewing every rendered page.
